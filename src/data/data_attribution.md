# NRC Dataset Attribution

The JSON dataset (`nrc.json`) contained in this directory originates from the open-source repository created by **[chuuhtetnaing/myanmar-nrc-format-dataset](https://github.com/chuuhtetnaing/myanmar-nrc-format-dataset)**.

We deeply appreciate the effort put into scraping, structuring, and maintaining this dataset. Full credit for the raw data goes to the original author. 

### Why is this here?
We have included this data locally within our package to ensure zero external dependencies and fast, synchronous loading for our ESM/CJS wrapper utility. 

If you are looking for the original data source or wish to contribute to the dataset itself, please visit the original repository linked above.
